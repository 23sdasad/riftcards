# 客户端界面

本文是 Godot 客户端界面的长期约定：布局、组件、视觉语言、交互状态和小窗口规则。规则与协议分别以[游戏规则](../product/game-rules.md)和[协议](../contracts/protocol.md)为准；界面只渲染投影并提交意图。

## 目标与边界

- 对手在上、自己在下：符合两人对战的视角习惯。
- **操作优先**：结束回合与认输紧跟对手区之后，不放在手牌下方；窗口变小也必须在首屏可见。
- 事件面板是次要信息：固定小高度、可折叠，不挤占对局区。
- 界面不计算费用、伤害、目标合法性或胜负：只显示服务端给的数值，非法操作由服务端拒绝并显示错误码。
- 界面是**代码构建**的（`new Label()`/`new Button()`），不是 `.tscn` 场景：这样布局与组件能被编译器和单元测试覆盖，无需美术资源即可演进。将来要交给美术时再引入场景与主题资源，不影响 Core 分层。

## 布局

1280×800 参考尺寸，从上到下：

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ 顶栏   riftcards │ 状态文本 │ [服务器地址        ] [连接] [进入匹配]        │
├────────────────────────────────────────────────────────────────────────────┤
│ 终局横幅（仅对局结束时显示）  胜利 / 败北 · 原因                            │
├────────────────────────────────────────────────────────────────────────────┤
│ ┌ 对手 ──────────────────────────────────────────────────────────────────┐ │
│ │ 对手（座位 1）  HP 0  费用 5 │ 牌库 21 │ 手牌 3        [攻击此英雄]      │ │
│ │ 场地 ▸ [持盾者 1/3 守卫] [王庭卫兵 3/6 守卫] …（横向滚动）             │ │
│ └────────────────────────────────────────────────────────────────────────┘ │
│ ┌ 你 ────────────────────────────────────────────────────────────────────┐ │
│ │ 场地 ▸ [余烬侍从 2/1 · 攻击 0] [石哨兵 2/5 守卫 · 攻击 1] …            │ │
│ │ 你（座位 0）· 你的回合  HP 11  费用 4 │ 牌库 20 │ 手牌 2               │ │
│ └────────────────────────────────────────────────────────────────────────┘ │
│                       ▲ 以上是唯一可滚动的战场（窗口变小只压缩这里）       │
├────────────────────────────────────────────────────────────────────────────┤
│ 提示行  请选择目标：任意单位或对手英雄                                     │
├────────────────────────────────────────────────────────────────────────────┤
│ 手牌（费用 4） [治疗之光 / 法术 · 2 费] [持盾者 / 单位 · 2 费] …（横向滚动）│
├────────────────────────────────────────────────────────────────────────────┤
│ 第 12 回合 · 你的回合 · revision 46                 [结束回合] [认输]      │
├────────────────────────────────────────────────────────────────────────────┤
│ 事件  待播放 0 │ 已消费 seq 104            [折叠] [跳过动画]                │
│ #104 对局结束：你获胜（英雄阵亡）                                          │
└────────────────────────────────────────────────────────────────────────────┘
```

**只有战场在滚动区里**：手牌与回合条固定在底部（卡牌游戏习惯，也让操作永远留在首屏），事件面板固定在更下方。这份布局由 1280×800 与 900×480 两种尺寸的截图验证。

## 组件

| 组件 | 位置 | 内容 |
| --- | --- | --- |
| `TopBar` | 应用壳 | 标题、会话状态、服务器地址输入、连接、进入匹配 |
| `TerminalBanner` | 应用壳 | 仅终局显示：胜利/败北、结束原因 |
| `HeroPanel` | 对局面板 | **单行**：归属与回合指示、HP、费用/牌库/手牌数、对手英雄的攻击入口 |
| `UnitButton` | 对局面板 | 名称 + `攻击/生命` + 守卫徽章 + 剩余攻击次数（124×48） |
| `CardButton` | 对局面板 | 名称 + `单位/法术 · N 费`，两行居中（132×52） |
| `TurnBar` | 对局面板（固定底部） | 回合数、当前行动方、`revision`、结束回合、认输 |
| `HintLine` | 对局面板（战场与手牌之间） | 当前该做什么，或服务端错误码 |
| `EventPanel` | 应用壳（固定底部） | 可读事件文本、待播放数量、缺帧提示、折叠、跳过动画 |

## 视觉语言

颜色（深色棋盘）：

| 用途 | 值 |
| --- | --- |
| 页面背景 | `#151821` |
| 面板背景 / 边框 | `#1f2430` / `#333a4a` |
| 主文字 / 次要 / 弱化 | `#e6e9f0` / `#9aa4b8` / `#6b7385` |
| 你的回合、可选 | `#4ade80` |
| 对手回合、注意 | `#f0a23c` |
| 危险、拒绝、低生命 | `#ef5350` |
| 守卫徽章 | `#5b8def` |
| 选中边框 | `#f5c451` |

字号：标题 20、面板标题 15、正文 14、说明 12。间距：面板内边距 10、元素间距 6、区块间距 10。圆角 6。

状态色规则：

- 生命：投影不含最大生命（`PlayerView` 只有 `hp`），因此界面只按服务端数值显示，并在 `HP 0`（阵亡）时用危险色；要做比例着色需先在协议里补 `maxHealth`。
- 回合条：轮到自己用绿色，对手回合用橙色。
- 单位：`守卫` 用蓝色徽章；剩余攻击为 0 时整体弱化（只反映服务端数值，不推断原因）。
- 拒绝：提示行用危险色显示 `服务端拒绝：<code>`。

## 交互状态

| 状态 | 可用操作 | 提示行 |
| --- | --- | --- |
| 未连接 / 未入局 | 连接、进入匹配 | 连接后点「进入匹配」。 |
| 等待对手 | 认输 | 等待对手行动。 |
| 你的回合 | 手牌、己方单位、结束回合、认输 | 点击手牌出牌；点己方单位后选择攻击目标。 |
| 已选法术待目标 | 任意单位、对手英雄 | 请选择目标：任意单位或对手英雄。 |
| 已选攻击者待目标 | 对手单位、对手英雄 | 请选择攻击目标：对手单位或对手英雄。 |
| 对局结束 | 无（按钮禁用） | 对局已结束。 |

选择状态由 `MatchBoard` 管理，快照校正后自动清理无效选择；界面不自行判断目标合法性。

## 事件文本

事件面板把事件类型与载荷渲染成可读句子，并保留 `#seq` 前缀（`revision` 显示在回合条上，不逐行重复）：

| 事件 | 文本 |
| --- | --- |
| `turn_started` | 第 N 回合开始：你/对手（费用 X） |
| `turn_ended` | 回合结束：你/对手 |
| `card_drawn` | 你/对手抽了 1 张牌（手牌 X） |
| `card_burned` | 手牌已满，烧掉 1 张牌 |
| `card_played` | 你/对手打出 卡名 |
| `unit_summoned` | 你/对手召唤 卡名（攻击/生命，守卫） |
| `attack_resolved` | 卡名 攻击 卡名（造成 X，受到 Y） |
| `damage_dealt` | 目标 受到 X 点伤害（HP A→B） |
| `healed` | 目标 恢复 X 点生命（HP A→B） |
| `unit_died` | 卡名 死亡 |
| `fatigue_damage` | 疲劳：你/对手受到 X 点伤害（HP A→B） |
| `match_ended` | 对局结束：你获胜/你败北（原因） |
| 未知类型 | 未知事件 `<type>`（已忽略） |

未知类型只显示与记录，不改变任何状态（见[事件队列与表现层解耦](../../ai-docs/task/009-event-queue-presentation.md)）。

## 小窗口规则

- **只有战场在滚动区里**：手牌与回合条固定在底部，窗口再小也能看到并点到「结束回合」。
- 场地行与手牌行使用横向滚动容器，单位或手牌变多时不换行、不挤压英雄区。
- 事件面板默认展开、固定 96px 高；窗口高度小于 620px 时自动折叠为单行头部（头部仍显示待播放数量与已消费 `seq`），玩家手动展开优先于自动折叠。
- 纵向尺寸常量：卡牌 132×52、单位 124×48、事件面板 96、区块间距 8、面板内边距 10。这些值经过 1280×800 与 900×480 两种尺寸的截图验证。
